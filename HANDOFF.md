# Genogram — handoff

- **What:** standalone family genogram maker for residents and nurses. Owner: Ma. Isabella P. Navarro, MD (`isaymotion`). She does not code; explain plainly. Repo `isaymotion/genogram` (public); `main` is the site (GitHub Pages: https://isaymotion.github.io/genogram/ once she switches Pages on: Settings > Pages > Deploy from a branch > main, / (root)). `dev-tools` = main + `tools/tests` + this file; never merge into main.
- **Built with** the `isaymotion-app-design` skill (scaffold `new_app.py`, hue teal to match her pixel-art icon; `check_design.py --browser` must pass). Storage prefix `g:v1:`, cache prefix `genogram-`. Icon: her own image, `icons/icon-source.png`; regenerate with `make_icons.py icons/icon-source.png --out icons --bg "#023B4C"`.
- **Files:** `js/genogram-engine.js` (layout + SVG, `window.Geno`; the block between BEGIN/END shared block is copied verbatim from PsychInterview `index.html` "Family members and genogram"; only local change is `genoPtDead`. Re-copy when either app's drawing changes). `js/app.js`: shell + the "APP VIEWS: genogram maker" section (home, `#/chart/<id>[/lines|/view]`, `#/symbols`, `#/guide`, export, search index). Styles at the end of `css/app.css` ("Genogram maker screens").
- **Data:** `store 'charts'` = `{order:[ids], byId:{id:{id,title,created,updated,ptName,ptAge,ptSex,ptOcc,ptCond,ptFill,ptDead,parentsRel,ptRel,byAge,showTitle,family:[…],links:[{a,b,type}]}}}`; `toEngine(c)` maps it to the engine's case shape. Member fields are the engine's (`id,name,rel,age,sex,status,psych,withPt,twin,occ,cond,count,of,relStatus`).
- **Export:** PNG via canvas; PDF = that picture as JPEG inside a hand-written one-page A4 PDF (`pdfFromJpeg`). Installed apps use the share sheet.
- **Tests:** `python3 tools/tests/t_app.py <app folder> <out folder>` (playwright; builds a family by hand on a phone-size page, checks saved data, age order, PNG/PDF downloads, sample, duplicate/delete, search, dark tablet screenshots). Passing = `errors []`.
- **Release recipe:** bump `version` in `data/app-meta.js`, `VERSION` in `sw.js`, add a `data/changelog.js` entry (all three must agree), run `t_app.py` and `check_design.py . --browser`, delete `_qa/`, push straight to `main` (her standing instruction: push direct, no PR).
- **Restore in a new chat:** `git clone https://github.com/isaymotion/genogram && cd genogram && git fetch origin dev-tools && git worktree add ../genogram-dt origin/dev-tools`, then `python3 ../genogram-dt/tools/tests/t_app.py "$PWD" /tmp/geno-out` (expect `errors []`) and `python3 <isaymotion-app-design skill>/scripts/check_design.py . --browser` (expect PASS; delete `_qa/`).
